# 1.4.1 Use of Color

**Level:** A | **Standard:** WCAG 2.2
**Spec:** <https://www.w3.org/TR/WCAG22/#use-of-color>

## Why manual

Detecting color-only communication requires understanding what the color conveys in context — status meaning, required-field distinction, chart legend meaning — and whether a redundant non-color signal is present. CSS analysis can flag inline color declarations but cannot determine semantic intent or verify the presence of visual redundancy.

## What to verify

> "Color is not used as the only visual means of conveying information, indicating an action, prompting a response, or distinguishing a visual element."

Note (non-normative): This criterion addresses color perception specifically. Other visual presentation concerns are addressed under Guideline 1.3 (Adaptable), including programmatic access to color.

Applies to:
- **Status indicators:** error/warning/success distinguished by red/yellow/green only.
- **Required field markers:** asterisk styled in red only.
- **Chart/graph legends:** series distinguished by color fill only.
- **Link text:** underline removed so links are color-distinguished from surrounding text.
- **Active/selected state:** highlighted by background color change only.

## Common failure modes

- Form validation shows errors by turning a border red with no text or icon indicator.
- A pie chart labels slices by color in a legend with no pattern or label on the slice.
- Required fields marked with a red asterisk that is also the only visual signal.
- Navigation links styled to remove underlines, relying solely on color contrast to distinguish them from body text.
- A "step completed" checkmark is a green circle — no icon or text confirms completion for color-blind users.

## Attestation guidance

To attach evidence to an `attest` call (`ra11y-kb://criteria/wcag22/1.4.1`):

- Audit status indicators, required-field markers, form error states, charts, and interactive elements.
- For each, identify whether color is the sole distinguishing signal.
- Verify a redundant non-color signal exists: text label, icon, border, underline, pattern, or shape difference.
- Test with a grayscale simulation (browser devtools or a color-blind emulation plugin).

Evidence: screenshot or DOM listing of affected components, description of redundant signal, grayscale test result.
