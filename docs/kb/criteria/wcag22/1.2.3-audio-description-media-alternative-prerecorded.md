# 1.2.3 Audio Description or Media Alternative (Prerecorded)

**Level:** A | **Standard:** WCAG 2.2
**Spec:** <https://www.w3.org/TR/WCAG22/#audio-description-or-media-alternative-prerecorded>

## Why manual

Determining whether a synchronized video has adequate audio description or a full text alternative requires watching the video and evaluating whether visual-only information (scene changes, text on screen, actions without dialogue) is communicated. Static analysis cannot assess equivalence.

## What to verify

> "An alternative for time-based media or audio description of the prerecorded video content is provided for synchronized media, except when the media is a media alternative for text and is clearly labeled as such."

Key definitions:
- **Synchronized media:** audio or video synchronized with another format, or with time-based interactive components.
- **Audio description:** narration added to the audio track of a video to describe important visual information.
- **Alternative for time-based media:** a document providing a text equivalent of visual and audio information.
- **Exception:** does not apply when the media is a media alternative for text and is clearly labeled as such.

Note: SC 1.2.5 (Level AA) requires audio description specifically. This criterion (Level A) allows a full text/audio alternative as an acceptable substitute.

## Common failure modes

- A marketing video with text-on-screen and visual demonstrations has neither audio description nor a full text transcript.
- Captions are provided but no audio description covers scenes with significant visual-only content.
- A "media alternative" label is applied to a video that adds information not in the surrounding text.
- Audio description exists but omits important actions, text appearing on screen, or scene context.

## Attestation guidance

To attach evidence to an `attest` call (`ra11y-kb://criteria/wcag22/1.2.3`):

- Enumerate all synchronized media (`<video>` with both audio and video tracks).
- For each: confirm either (a) a full text/audio alternative exists and is linked, or (b) audio description of all visual-only information is present.
- Verify any "media alternative for text" label is accurate — the surrounding text must be a full equivalent.
- Check that audio description covers: text on screen, actions, gestures, scene changes, and any visual-only information.

Evidence: list of synchronized media elements, alternative type (text alt / audio description), URL, and equivalence check result.
