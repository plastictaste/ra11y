# 3.2.1 On Focus

**Level:** A | **Standard:** WCAG 2.2
**Spec:** <https://www.w3.org/TR/WCAG22/#on-focus>

## Why manual

Finders flag `onFocus` handlers statically, but determining whether the handler *initiates a change of context* (vs. a cosmetic change like a tooltip or highlight) requires understanding what the handler does at runtime. Many `onFocus` handlers are benign (e.g., scrolling into view, showing a hint); only those that navigate, submit, or open new windows violate this criterion.

## What to verify

> "When any user interface component receives focus, it does not initiate a change of context."

Definition — **change of context:** major changes that, if made without user awareness, can disorient users. Changes of context include: changes of user agent, changes of viewport, changes of focus, and changes of content that change the meaning of the page. Changes in layout or content that do not change the meaning are not changes of context.

Examples of changes of context:
- Opening a new window.
- Moving focus to a different component programmatically.
- Navigating to a new page.
- Significantly reordering page content.

## Common failure modes

- A navigation menu item opens a submenu AND moves focus into it on `onFocus` without a user gesture.
- A select/dropdown initiates form submission when a field receives focus.
- Focusing a link opens a new browser window.
- An autocomplete field navigates to a search result page on focus.
- A carousel slide advances when its control receives focus.

## Attestation guidance

To attach evidence to an `attest` call (`ra11y-kb://criteria/wcag22/3.2.1`):

- Tab through every interactive control: links, buttons, inputs, selects, custom widgets.
- For each element with an `onFocus` / `focus` event handler, observe what happens upon receiving focus.
- Confirm: no page navigation, no new window, no form submission, no significant content reorder occurs solely from receiving focus.
- Check JavaScript for `window.location`, `window.open`, `form.submit()`, `router.push()` inside focus handlers.

Evidence: list of elements with focus handlers, behavior observed on focus, pass/fail per element.
