# 1.2.1 Audio-only and Video-only (Prerecorded)

**Level:** A | **Standard:** WCAG 2.2
**Spec:** <https://www.w3.org/TR/WCAG22/#audio-only-and-video-only-prerecorded>

## Why manual

Detecting the presence of `<audio>` and `<video>` elements is automatable; determining whether a transcript or alternative exists and whether it is equivalent requires reading and evaluating linked content. Static analysis cannot verify equivalence of alternatives.

## What to verify

> "For prerecorded audio-only and prerecorded video-only media, the following are true, except when the audio or video is a media alternative for text and is clearly labeled as such:
> - **Prerecorded Audio-only:** An alternative for time-based media is provided that presents equivalent information for prerecorded audio-only content.
> - **Prerecorded Video-only:** Either an alternative for time-based media or an audio track is provided that presents equivalent information for prerecorded video-only content."

Key definitions:
- **Prerecorded:** information that is not live.
- **Audio-only:** a time-based presentation that contains only audio (no video and no interaction).
- **Video-only:** a time-based presentation that contains only video (no audio and no interaction).
- **Exception:** does not apply when the media is a media alternative for text and is clearly labeled as such.

## Common failure modes

- A podcast embedded with `<audio>` has no linked transcript.
- A muted product-demo video (`<video>` without an audio track) has no descriptive text alternative.
- A transcript is provided but does not cover all spoken information (partial equivalence).
- The media is labeled as "supplemental" but the surrounding text does not adequately substitute.
- An `<audio>` with `aria-label` but no external transcript link.

## Attestation guidance

To attach evidence to an `attest` call (`ra11y-kb://criteria/wcag22/1.2.1`):

- Enumerate every `<audio>` and `<video>` element in the scanned files.
- For audio-only: confirm a transcript (linked or inline) covering all spoken content is present and equivalent.
- For video-only: confirm either a text alternative describing all visual information or an audio track exists.
- Verify the exception label is present when media is presented as a text alternative.
- Screen-reader test: confirm the alternative is reachable without mouse.

Evidence: list of media elements, type (audio-only / video-only), URL or location of alternative, equivalence check result.
