# `aria/disabled-link-surrogate`
- **Severity:** warning
- **Scope:** document
- **Satisfies:** `wcag22:4.1.2`, `wcag21:4.1.2`
- **Applies to:** .html, .htm, .tsx, .jsx
## What it checks
Non-interactive elements (span, div, i, b, em) used as disabled-link surrogates (typically pagination's Previous/Next when there's no target) must expose the disabled state via aria-disabled, role=link + aria-disabled, or a disabled-state word in visible text — otherwise screen readers read the element as static prose and the disabled signal is lost.
## Why it matters
Pagination widgets and similar "row of links" components often render the unavailable control as a styled `<span>` (e.g. `<span class="previous">‹</span>` on the first page, where there is no prior page to link to). CSS greys it out for sighted users, but the surrounding `<a>` siblings are exposed as links in the accessibility tree while the surrogate is exposed as plain text — the disabled-state signal reaches sight but not the accessibility tree. WCAG 4.1.2 requires that component states be programmatically determinable. Fix by adding `aria-disabled="true"` (plus `role="link"` if the surrogate is standing in for a link), or by including a disabled-state word in the visible text so the accessible name carries the signal.
## Normative quote
> For all user interface components (including but not limited to: form elements, links and components generated by scripts), the name and role can be programmatically determined; states, properties, and values that can be set by the user can be programmatically set; and notification of changes to these items is available to user agents, including assistive technologies.
## Good example
```tsx
<ul class="pagination">
  <li><span class="previous" aria-disabled="true" role="link">&lsaquo; Previous</span></li>
  <li><a class="page" href="/p/2">2</a></li>
  <li><a class="page" href="/p/3">3</a></li>
</ul>
```
## Bad example
```tsx
<ul class="pagination">
  <li><span class="previous">&lsaquo; Previous</span></li>
  <li><a class="page" href="/p/2">2</a></li>
  <li><a class="page" href="/p/3">3</a></li>
</ul>
```
