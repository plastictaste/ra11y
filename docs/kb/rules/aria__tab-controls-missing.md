# `aria/tab-controls-missing`
- **Severity:** error
- **Scope:** node
- **Satisfies:** `wcag22:4.1.2`, `wcag21:4.1.2`, `wcag22:1.3.1`, `wcag21:1.3.1`
- **Applies to:** .html, .htm, .tsx, .jsx
## What it checks
role=tab elements must reference their panel via aria-controls; role=tabpanel elements must be labelled by a tab via aria-labelledby (reciprocal-pair invariant).
## Why it matters
The WAI-ARIA tabs pattern is a reciprocal-pair contract: each tab declares its panel via aria-controls, each panel names the tab that owns it via aria-labelledby. Without aria-controls on the tab, assistive tech has no programmatic way to know which DOM node the tab activates — keyboard users can press Right-arrow between tabs but the panel relationship is invisible. Without aria-labelledby on the panel (and no tab pointing back), the panel content reads as 'an unnamed region' instead of being announced as 'Tab Name, panel'. The reciprocal half of the pair is also enforced — a dangling aria-controls token (target id absent or not a tabpanel) is the same silent wire-up failure as a broken aria-labelledby token: the author wrote the attribute, but nothing resolves at runtime, and sighted authors who don't run a screen reader during development have no signal. The three branches together cover the failure modes the WAI-ARIA Authoring Practices documents as the most common tabs-pattern bugs.
## Normative quote
> For all user interface components (including but not limited to: form elements, links and components generated by scripts), the name and role can be programmatically determined; states, properties, and values that can be set by the user can be programmatically set; and notification of changes to these items is available to user agents, including assistive technologies.
## Good example
```tsx
<div role="tablist">
  <button role="tab" aria-selected="true" aria-controls="panel-1" id="tab-1">Tab 1</button>
  <button role="tab" aria-selected="false" aria-controls="panel-2" id="tab-2">Tab 2</button>
</div>
<div role="tabpanel" id="panel-1" aria-labelledby="tab-1">Panel 1 content</div>
<div role="tabpanel" id="panel-2" aria-labelledby="tab-2">Panel 2 content</div>
```
## Bad example
```tsx
<div role="tablist">
  <button role="tab" aria-selected="true">Tab 1</button>
</div>
<div role="tabpanel">Panel 1 content</div>
```
