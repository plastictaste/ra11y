# `keyboard/interactive-div-role-missing`
- **Severity:** warning
- **Scope:** project
- **Satisfies:** `wcag22:4.1.2`, `wcag22:2.1.1`, `wcag21:4.1.2`, `wcag21:2.1.1`, `section508:4.1.2`, `section508:2.1.1`, `en301549:9.4.1.2`, `en301549:9.2.1.1`
- **Applies to:** .html, .htm, .tsx, .jsx, .ts, .js
## What it checks
When a JS file binds a click handler (via document.querySelector / getElementById / etc.) to a non-interactive element (<div>, <span>, <li>, <img>) and the resolved HTML element has no role, tabindex, or accessible name, emit a finding so the agent can change the markup to <button> or add the missing ARIA wiring.
## Why it matters
A vanilla-JS app calling `document.querySelector('.action').addEventListener('click', save)` against a `<div class="action">` produces an interaction sighted mouse users can perform but keyboard and screen-reader users cannot — the host element is neither focusable (no `tabindex`) nor announced as a button (no `role`). This rule pairs JS click-attach sites with their HTML targets and emits at the HTML element, since that's the file the agent edits to fix it. The suggestion names the JS site so the agent can verify the resolution before changing the markup. Two SCs are violated simultaneously: 4.1.2 (the role isn't programmatically determined) and 2.1.1 (the element isn't keyboard-operable).
## Normative quote
> For all user interface components (including but not limited to: form elements, links and components generated by scripts), the name and role can be programmatically determined; states, properties, and values that can be set by the user can be programmatically set; and notification of changes to these items is available to user agents, including assistive technologies.
## Good example
```tsx
<!-- index.html -->
<button type="button" class="action">Save</button>
<script src="./app.js"></script>

// app.js
document.querySelector('.action').addEventListener('click', save);
```
## Bad example
```tsx
<!-- index.html -->
<div class="action">Save</div>
<script src="./app.js"></script>

// app.js
document.querySelector('.action').addEventListener('click', save);
```
