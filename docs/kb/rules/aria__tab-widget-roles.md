# `aria/tab-widget-roles`
- **Severity:** error
- **Scope:** node
- **Satisfies:** `wcag22:4.1.2`, `wcag21:4.1.2`, `wcag22:1.3.1`, `wcag21:1.3.1`
- **Applies to:** .html, .htm, .tsx, .jsx
## What it checks
Tab-widget idioms (data-toggle=tab, data-bs-toggle=tab, role=tab) must declare the full WAI-ARIA tabs role triple — role=tablist on the parent, role=tab plus aria-selected on every member, and role=tabpanel on every controlled panel.
## Why it matters
A tab widget assembled out of `<ul><li><a data-toggle="tab">…</a></li></ul>` (Bootstrap 4) or `<button data-bs-toggle="tab">…</button>` (Bootstrap 5) renders correctly to a sighted user — the active tab is highlighted, clicking switches panels, the layout looks right. But the WAI-ARIA tabs pattern is a programmatic-role contract: assistive tech announces the widget as "tablist, tab 1 of 3, selected" only when the role triple (tablist parent + role=tab member + role=tabpanel target) and the `aria-selected` state are all present. A half-implemented widget — `data-toggle="tab"` providing the JavaScript hook but no roles or selection state — is announced as "list, link, link, link" with no relationship between the links and the panels. Screen-reader users hear three unrelated links and a generic block of text below; keyboard users get focus order but no "tabs" semantics, so the standard arrow-key tab navigation isn't hinted. This rule fires the moment any tab-idiom signal is seen, and reports the specific role-triple gaps so the fix is mechanical: add the missing roles, add aria-selected, point aria-controls at the panel.
## Normative quote
> For all user interface components (including but not limited to: form elements, links and components generated by scripts), the name and role can be programmatically determined; states, properties, and values that can be set by the user can be programmatically set; and notification of changes to these items is available to user agents, including assistive technologies.
## Good example
```tsx
<div role="tablist">
  <button role="tab" aria-selected="true" aria-controls="panel-1" id="tab-1">Tab 1</button>
  <button role="tab" aria-selected="false" aria-controls="panel-2" id="tab-2">Tab 2</button>
</div>
<div role="tabpanel" id="panel-1" aria-labelledby="tab-1">Panel 1 content</div>
<div role="tabpanel" id="panel-2" aria-labelledby="tab-2">Panel 2 content</div>
```
## Bad example
```tsx
<ul>
  <li><a data-toggle="tab" href="#panel-1">Tab 1</a></li>
  <li><a data-toggle="tab" href="#panel-2">Tab 2</a></li>
</ul>
<div id="panel-1">Panel 1</div>
<div id="panel-2">Panel 2</div>
```
